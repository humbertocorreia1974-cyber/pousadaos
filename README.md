# 🚀 PousadaOS

> Plataforma completa de gestão hoteleira (PMS) para rede de pousadas e hotéis boutique, cobrindo reservas, recepção, housekeeping, folio, gerência e portal do hóspede — com app mobile para recepção e camareira.

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Configurar variáveis de ambiente
cp .env.example .env # se aplicável

# 3. Iniciar servidor de desenvolvimento
npm run dev
```
